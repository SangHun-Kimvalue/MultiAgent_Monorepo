배포 사본이며 정본 절 변경 시 함께 동기화한다.

### LESSON-M061 · 무인 실행 단계는 사용자 확인 대화상자에 의존하면 완주하지 못한다 *(2026-08-20 병합 재발급 — 구 M052)*

무인 실행 단계가 파일을 뷰어/브라우저 패널로 열면, 권한 bypass 설정과 **무관하게** 사용자 확인
대화상자가 뜰 수 있고 그 단계는 입력 대기로 홀딩된다. 모달 호출은 반환 자체를 하지 않을 수
있으므로 "떠도 폴백"은 성립하지 않는다 — **1차 불변은 표시 호출을 실행하지 않는 것**이다.

- **경계는 세션이 아니라 실행 단계 단위로 선언한다**: 각 leg·서브에이전트·워크플로 단계는 시작 전
  `completion_mode=unattended|interactive_checkpoint`를 명시한다. `unattended`는 사람 입력 없이
  timeout 내 종결해야 하고, `interactive_checkpoint`는 전경 소유자·예상 확인창·대기 허용 시점을
  사전 선언한 경우에만 허용된다. (세션 전체가 대화형이어도 그 안의 백그라운드 leg는 unattended다.)
- `unattended` 단계는 **확인창 가능성이 있는 표시 호출(뷰어/브라우저 패널 열기)을 실행하지 않는다**
  — 프로젝트 안 파일이라도. 불가피한 외부 호출은 별도 프로세스 + 명시 wall timeout + 강제 종료 +
  사전 기록된 대체 산출물을 갖춘 어댑터 경유만 허용한다(폴백 코드 도달 불능 경로 차단).
- 자기 검증은 **비대화형으로 실행 가능한 검증만** 수행한다(헤드리스 렌더·파스·좌표 실측 등).
  비대화형으로 닫을 수 없는 검증(글꼴 대체·겹침·색 대비·실제 뷰어 렌더 차이 등)은 렌더 이미지·로그
  증거를 산출한 뒤 **NOT CLAIMED 또는 명시적 human checkpoint로 넘긴다** — 제한된 계측을 시각 QA
  PASS로 과장하지 않는다.
- 사용자 전달 산출물은 파일로 저장 후, **해당 환경에서 확인창 없음이 검증된 비대화형 전송 채널**로만
  전달한다. 미검증 채널이면 저장 완료 + `delivery_pending` 표시를 남기고 **비차단 종료**한다(전달
  단계로 홀딩을 이전하지 않는다).
- 산출물 저장 위치: **gitignore 경로가 운영 기본값**. tracked 경로가 필요하면 Gate 시점 live-tree
  baseline manifest에 분류·hash 고정한다(methodology LESSON-M060의 분류 규칙 — gitignore 한정이
  LESSON-M060의 내용이라는 뜻이 아니다).
- 홀딩 의심 시 run 저널 started/result 수·산출 디렉터리 mtime **실측**으로 판정한다 — 추측 재발사 금지.
- **`interactive_checkpoint` 단계와 대화형 세션 작업(pptx/xlsx/docx 등 문서 미리보기 포함)에는
  적용하지 않는다.** 단 이 규칙만을 근거로 **사용자가 요청한 대화형 미리보기를 거부해서는 안 되며**,
  실행 불가 시 사유·대체 증거·NOT CLAIMED 범위를 보고한다(뷰어 실행을 강제하는 규칙도 아니다).
